등락률 (전일 기준가 대비)

시장 랭킹이 같은 집계 시각에 제공한 현재가·전일 기준가·등락률을 사용합니다. 빨강 ▲ 상승 / 파랑 ▼ 하락(한국식 색).

시장 랭킹

토스증권 Open API가 제공하는 시장 전체 거래대금·거래량·상승·하락 상위 종목입니다. 거래대금·거래량은 실시간 기준이고 상승·하락은 당일 기준입니다.

거래량과 거래대금

거래량은 당일 누적 체결 수량(주), 거래대금은 당일 누적 체결 금액(원)입니다. 선택한 탭의 순위대로 표시합니다.

봉(캔들)

일정 기간(1분·1일)의 시가·고가·저가·종가를 막대 하나로 표현. 몸통은 시가~종가, 위아래 꼬리는 고가·저가.

🚨 가격 급변동 (PRICE_SPIKE)

현재가가 직전 평균가 대비 ±일정 % 이상 급등/급락. 단기 이상 변동을 잡습니다.

🚨 가격제한폭 도달 (PRICE_LIMIT)

하루 최대 변동폭(±30%)인 상한가/하한가에 도달하거나 근접.

🚨 호가 불균형 (ORDERBOOK_IMBALANCE)

호가창에서 사겠다고 걸어둔 대기물량(매수 잔량)과 팔겠다고 걸어둔 물량(매도 잔량)의 합을 비교합니다. 매수 잔량이 크면 매수 우위, 매도 잔량이 크면 매도 우위로 표시합니다. 호가는 취소될 수 있어 실제 체결·불공정거래를 뜻하지 않으며 지속 여부와 가격·체결 흐름을 추가 확인해야 합니다.

🚨 가격·거래량 동시 급증 (PRICE_VOLUME_SURGE)

가격 변동과 1분 거래량이 각각의 기준을 같은 평가에서 모두 넘은 경우입니다. 단일 신호보다 검토 우선순위를 높이되 시장 전체 움직임과 공개 이벤트를 함께 확인합니다.

🚨 거래량 급증 (VOLUME_SURGE)

최근 봉의 거래량이 직전 평균의 N배 이상. 갑작스런 매매 폭증을 포착합니다.
